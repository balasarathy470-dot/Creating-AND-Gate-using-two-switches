# Bluetooth-Based LED Control Using MIT App Inventor

&nbsp;

## 1\. Statement

&nbsp;

This project controls an LED remotely using a mobile application designed with MIT App Inventor. An HC-05 Bluetooth module provides wireless communication between the mobile phone and Arduino Uno. The user can turn the LED ON or OFF through the mobile app.

## 2\. Materials Required

&nbsp;

Arduino Uno

HC-05 Bluetooth Module

LED

Resistor

Breadboard

Jumper Wires

Android Mobile Phone

USB Cable

MIT App Inventor

## 3\. Procedure

&nbsp;

Connect the LED to the Arduino Uno through a suitable resistor.

Connect the HC-05 Bluetooth module to the Arduino for wireless communication.

Develop a simple ON/OFF control interface using MIT App Inventor.

Pair the mobile phone with the HC-05 Bluetooth module.

Upload the Arduino program to receive Bluetooth commands.

Press ON in the mobile application to switch the LED ON.

Press OFF to switch the LED OFF.

## 4\. Working

&nbsp;

The MIT App sends control commands through the mobile phone's Bluetooth connection. The HC-05 receives these commands and passes them to the Arduino Uno. The Arduino processes the received command and controls the LED accordingly.

ON command → Arduino → LED ON

OFF command → Arduino → LED OFF

## 5\. Advantages

&nbsp;

Wireless LED control

Simple and low-cost system

Easy-to-use mobile interface

No physical switch required

Can be extended to control multiple devices
