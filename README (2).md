# CREATING AND GATE USING TWO SWITCHES

&nbsp;

## 1\. Statement

&nbsp;

&nbsp;

An AND gate is a basic digital logic gate in which the output becomes ON only when both inputs are ON. This project demonstrates AND-gate operation using two switches, an LED, a dot matrix/perforated board, and a battery.

&nbsp;

## 2\. Materials Required

&nbsp;

&nbsp;

Dot matrix/perforated board

2 Push-button switches

LED

Resistor

Battery

Connecting wires

## 3\. Procedure

&nbsp;

&nbsp;

1\. Place the two switches, LED, and resistor on the dot matrix board.

2\. Connect the two switches in series with the LED circuit.

3\. Connect the battery as the power source.

4\. Press the first switch and observe the LED.

5\. Press the second switch while keeping the first switch pressed.

6\. The LED glows only when both switches are pressed, demonstrating AND-gate operation.

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

## 4\. Truth Table

&nbsp;

| Switch 1 | Switch 2 | Output |
| :---- | :---- | :---- |
| off | off | off |
| off | on | off |
| on | off | off |
| on | on | on |

&nbsp;

## 5\. Working

&nbsp;

&nbsp;

The two switches act as the two inputs (A and B). Since they are connected in series, current reaches the LED only when both switches are closed.

&nbsp;

Logic:

A AND B \= Output

&nbsp;

## 6\. Notes

&nbsp;

The LED represents the logic output.

The switches represent the logic inputs.

A resistor should be used to limit the current through the LED.

The circuit demonstrates the basic principle of an AND logic gate.
